# Computational Psychiatry Simulation

A modular Reinforcement Learning framework built from scratch in Python to simulate cognitive decision-making deficits in psychiatric conditions.

## Project Architecture
- `environment.py`: Contains the multi-armed bandit task logic.
- `agent.py`: Contains the baseline and modified learning engines.
- `main.py`: Coordinates the experimental loops and visualizations.

## Setup Instructions
1. Clone this repository.
2. Activate the virtual environment.
3. Install dependencies: `pip install numpy matplotlib`
4. Run `python main.py`
